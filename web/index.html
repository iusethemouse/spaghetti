    This tool allows you visualise pull request spaghetti.

    You can add repositories as columns, and then pull requests as cards within their cells. You can then add rows to the grid and arrange the pull request cards as you wish. If the branch targeted by a pull request has an open pull request itself, you can click the "#XX" button next to the branch name to automatically add that pull request to the grid.

    PRs can be arranged in any way you like, and you can connect them to indicate a dependency.

    You can also create tags at the bottom of the page, and assign them to PRs by clicking the empty circle in the top left corner of the card.

    Instructions
    1. Open GitHub token settings -> Generate new token -> Generate new token (classic).
    2. Name it spaghetti, choose an expiration, and select the repo scope.
    3. Generate the token and copy it.
    4. Beside the token, click Configure SSO → Authorize for your organization. SSO help
    5. Paste it above and click Connect.
